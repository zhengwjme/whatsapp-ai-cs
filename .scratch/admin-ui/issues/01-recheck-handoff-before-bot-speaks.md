# 01: 机器人发言前复查转人工期（竞态修复，先行重构）

**What to build:** 机器人正在生成回复或处于拟人延迟时，如果会话已经进入转人工期（任何来源），这条回复不再发给客户。每次机器人对外发言（正常回复、转人工流程之外的任何机器人消息）前，都重新检查转人工期；已进入就丢弃这条回复（不发送、不写会话历史），并收掉"正在输入"。转人工流程自己发出的转人工话术不受影响。这是后续"手动转人工"的前置：手动转人工不经过按会话串行的队列，必须靠这一步拦住机器人。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent
