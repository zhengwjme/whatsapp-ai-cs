# 05: 在界面里回复客户（运营发送）

**What to build:** 运营在会话详情里输入文字，直接发给客户，效果等同于在手机上回复：算作运营接管（开启或重新计满转人工期），以运营身份写入会话历史且只写一次。只发文字。连接适配器新增"以本号身份给会话发一条文字消息、返回消息 id"的能力；发送 id 要记下来，使回显不会被再当作运营接管重复记录。运营发送和客户消息走同一条按会话串行的队列，保证顺序。

**Blocked by:** 02

**Status:** ready-for-agent

- [x] 发送后：消息经适配器发出；历史末尾是一条运营发言；会话进入转人工期
- [x] 模拟该消息的回显随后到达，历史里不出现重复记录，也不再次处理
- [x] 适配器发送失败：API 返回错误；不写历史、不开转人工期
- [x] 空白内容被拒绝
- [x] 连接未处于已连接状态时，发送 API 返回明确的错误
- [x] 在手机上回复客户的运营接管行为不变
- [ ] 人工验收：发送失败时页面提示、输入框内容保留；未连接时发送按钮禁用并说明原因；真实 WhatsApp 上客户收到消息，手机端也能看到这条消息
