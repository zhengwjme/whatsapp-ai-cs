# 02: 管理界面骨架：本机访问、连接状态、只读会话列表和历史

**What to build:** 管理员 `npm start` 后，浏览器自动打开管理界面（只允许本机访问，见 ADR 0002）。页面默认英文、可切换中文，语言选择记在浏览器本地。页面顶部显示 WhatsApp 连接状态（已连接、断线重连中、需要登录、已登出）；会话列表按最后一条消息的时间倒序，显示电话号、最后一条消息的摘要和时间、是否在转人工期及剩余时长；点开会话看只读的会话历史，客户、机器人、运营三方分别标出，默认最近 200 条，可"加载更多"。列表、状态和打开着的会话每 3 秒轮询刷新。

本票建立：同进程的管理服务（`node:http`，只绑定 `127.0.0.1`，端口由新配置项 `ADMIN_PORT` 指定、默认 3000）；最小的连接适配器（本票只提供"查询当前连接状态"，由传输层实现并注入）；原生 HTML/JS 静态页面和 en/zh 字典；核心逻辑里的会话列表查询和历史分页查询；以及唯一的测试接缝：用随机端口启动管理服务、注入假连接适配器，测试里用 `fetch` 调用 HTTP API。

**Blocked by:** None (can start immediately)
