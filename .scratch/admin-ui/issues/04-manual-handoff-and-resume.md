# 04: 手动转人工与恢复接待

**What to build:** 管理员在会话详情里可以点"手动转人工"，让机器人立即停止接待该会话（进入转人工期，时长取当前配置），客户察觉不到：不发转人工话术、不写会话历史；对已在转人工期的会话再点会从此刻重新计满。管理员也可以点"恢复接待"，立即结束转人工期：不给客户发任何消息，客户下一条消息由机器人正常回复，并且机器人能看到转人工期间客户和运营说过的话。术语见 `CONTEXT.md` 的"手动转人工"和"恢复接待"。

**Blocked by:** 01, 02

**Status:** ready-for-agent

- [x] 手动转人工后：客户没收到任何消息；之后的客户消息只记录、不回复
- [x] 对已在转人工期的会话再次手动转人工，到期时间从此刻重新计满
- [x] 假 LLM 挂起时手动转人工，放行后机器人回复不发出、不写历史
- [x] 恢复接待后：客户没收到任何消息；之后的客户消息由机器人回复，发给模型的上下文里包含转人工期间的客户与运营发言
- [x] 对不在转人工期的会话恢复接待不报错
- [x] 两个操作都有 HTTP API，会话列表的状态随之变化
- [ ] 人工验收：会话详情页两个按钮按状态显示和可用，点后列表状态及时更新
