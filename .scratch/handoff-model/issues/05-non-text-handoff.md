# 05: 非文字消息转人工

**What to build:** 客户发来非文字消息（语音、无说明的图片/视频、文件）时，会话历史中以类型占位记录（如“[语音]”），发转人工话术并开启转人工期（归为“机器人无法回答”）。贴纸与表情回应不算消息，直接忽略。带说明文字的图片/视频仍按文字消息处理。Baileys 与 WAHA 两个传输层各自把原始消息归一化为带非文字类型的消息，自身不含判断逻辑。
