# 01: 统一转人工动作，转人工话术计入会话历史

**What to build:** 客户要求转人工时，机器人发出转人工话术、把话术以机器人身份记入会话历史、开启转人工期——这三步收拢成一个统一的转人工动作，供后续所有转人工来源复用（先行 prefactor）。仍保持“话术发送失败则不开启转人工期”。

**Blocked by:** None (can start immediately)

**Status:** done

- [x] 客户要求转人工后，会话历史末尾依次是该客户消息、机器人身份的转人工话术
- [x] 转人工话术发送失败时不开启转人工期，客户下一条消息仍会被机器人接待
- [x] 现有 e2e 与 selftest 全部通过（按新语义更新受影响断言，不删断言）
- [x] e2e 新增断言覆盖上述行为
